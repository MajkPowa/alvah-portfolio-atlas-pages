# ALVAH — Portfolio Atlas

Veřejný statický přehled 18 ověřených online projektů ALVAH Technologies: funkce, uživatelské postupy, technická náročnost a dostupné statistiky Google Search Console.

Tento repozitář obsahuje pouze sestavený web. Původní zdrojový audit a diagnostika přístupů do klientských systémů jsou uložené samostatně v soukromém repozitáři.

Datový snímek: **29. 10. 2026**. Search Console porovnává **30. 9.–27. 10. 2026** s **2.–29. 9. 2026**; kliknutí z Googlu nejsou celkoví návštěvníci webu. Chybějící výkaz neznamená nulu.

GitHub Pages publikuje větev `main` z kořenového adresáře. Soubor `.nojekyll` zachovává statické soubory bez převodu Jekyllem. Relativní cesty a hashové navigační odkazy umožňují provoz v podadresáři repozitáře.

Fonty mají přiložené licence v `assets/fonts/`.
